# ☕ CoffeeTime

Bienvenue sur **CoffeeTime**, un site vitrine moderne pour une cafétéria.  
Ce projet a été réalisé dans le cadre du **Projet 1 – Création d’un site web**.

---

## 🧭 Aperçu

CoffeeTime est un site web responsive en **HTML**, **CSS** et **JavaScript**.  
Il met en avant une ambiance chaleureuse et des produits artisanaux autour du café.

---

## 🌐 Fonctionnalités principales

- Barre de navigation fixe et fluide  
- **Slider d’accueil** automatique avec plusieurs images  
- Section “🧁 Produits phares” présentant les spécialités  
- Section “📖 Hakkımızda / À propos” avec photo et texte  
- Pied de page avec icônes de réseaux sociaux et coordonnées  
- Design responsive pour mobile et tablette

---

## 🛠️ Technologies utilisées

- **HTML5**  
- **CSS3**  
- **JavaScript (ES6)**  
- **Font Awesome** (pour les icônes)
